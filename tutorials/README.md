# OphAgent Tutorials

The tutorials describe the session engine, model roles, multimodal routing,
tool adapters, planning, execution, verification, Web UI, and extension
workflow.

- **English:** [Start the tutorial](en/index.md)
- **简体中文：**[开始阅读](zh-CN/index.md)

The pages use GitHub-flavoured Markdown and Mermaid diagrams. They can be read
directly on GitHub or in a Markdown viewer with Mermaid support.

> [!IMPORTANT]
> OphAgent is intended for research and clinical decision support. Tutorial
> examples illustrate software behaviour and are not medical diagnoses.
